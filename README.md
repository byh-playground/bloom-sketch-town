# Sketch Town

BLOOM 세계관의 협동 액션 게임입니다.

현재 최신 원본 **0.9.2**를 이관하고 BLOOM GameKit의 입력 지연 개선을 연결하는 중입니다. 아직 검증·배포된 게임은 없습니다.

## 기준

- 원본: [ChatGPT 작업 대화](https://chatgpt.com/c/6acbb656-c434-83ee-8707-75bf94af3680), 2026-10-12 15:53 UTC의 0.9.2 HTML 및 소스 ZIP
- 적용 예정 GameKit: dist `6d9125a58bf63e4b7b0f68a6882c30e9858172bc` (PR 43, protocol 3)
- 같은 방의 모든 peer는 같은 GameKit 번들을 사용합니다.

## 개발·배포

작업 브랜치와 main 대상 Draft PR에서 원본 이관·통합·검증을 진행합니다. 실제 게임 원본을 확인한 뒤 기존 게임과 같은 정적 GitHub Actions Pages 배포를 구성합니다.

[공통 개발 규칙](https://github.com/byh-playground/bloom-reference/blob/main/rules/development.html)과 [공통 프로젝트 관리 규칙](https://github.com/byh-playground/bloom-reference/blob/main/rules/project-management.html)을 따릅니다.
